# Dot Mole Whack

DotPad를 손끝으로 탐색하며 두더지 패턴을 찾아 잡는 접근성 게임입니다. 기본 모드는 시각장애인이 시간 압박 없이 독립적으로 플레이하도록 설계했습니다.

## 실행

- 게임: https://byeol-coder.github.io/dot-mole-whack/
- 임베드: https://byeol-coder.github.io/dot-mole-whack/?embed=1

별도 빌드 과정은 없습니다. `main`이 갱신되면 GitHub Pages에 자동 배포됩니다.

## 게임 모드

### 촉각 탐색 — 기본

- 두더지가 정답을 찾을 때까지 사라지지 않습니다.
- 등장할 때 정답 행·열을 음성으로 알려주지 않습니다.
- 오답에도 생명이나 라운드를 잃지 않습니다.
- 이동 횟수와 힌트 사용량을 바탕으로 점수를 계산합니다.

### 도전

두더지는 계속 유지되지만, 같은 이동·힌트 조건에서 더 빨리 찾을수록 높은 점수를 얻습니다.

## 보드와 라운드

- 입문: 3×3
- 보통: 4×3
- 확장: 5×4
- 5라운드 또는 10라운드

## 조작

| 입력 | 동작 |
| --- | --- |
| 방향키 | 커서 이동 |
| Enter / Space | 현재 칸 선택 |
| H | 도움말 |
| R | 현재 상태 듣기 |
| G | 단계형 방향 힌트 |
| T | 촉각 보드 다시 출력 |
| N | 새 게임 |
| 화면의 칸 터치·클릭 | 해당 칸으로 이동하고 선택 |

### DotPad 물리 키

- F1 / F2: 좌우 이동
- F3 / F4: 위아래 이동
- 왼쪽 패닝: 현재 상태
- 오른쪽 패닝: 방향 힌트
- 전체 패닝: 현재 칸 선택

## 촉각 패턴

- 좌측 상단 굵은 L자: 보드 시작점
- 각 칸의 작은 점: 공간 기준점
- 사각 테두리: 현재 커서
- 중앙의 굵은 십자: 두더지
- 가운데가 채워진 블록: 성공
- X 패턴: 오답

게임 시작 전 **촉각 튜토리얼**에서 패턴을 차례로 출력해 익힐 수 있습니다.

## 접근성

- 실제 `TW_TTS` 연결 및 브라우저 음성 폴백
- 정답 좌표 대신 선택형 단계 힌트 제공
- ARIA grid, 실시간 상태 영역, 키보드 포커스, 모달 포커스
- `prefers-reduced-motion`, 모바일 및 `?embed=1` 대응
- SDK나 기기가 없어도 화면·키보드·터치로 연습 가능

## DotPad 연결 조건

- HTTPS
- Chrome 89+ 또는 Web Bluetooth 지원 Edge
- Bluetooth가 켜진 DotPad
- 사용자의 직접적인 연결 버튼 클릭과 권한 허용

게임은 DotPad Web SDK v3.0.0을 연결 시점에 동적으로 불러옵니다. 논리 보드를 기기의 실제 그래픽 셀 크기로 변환하고 각 2×4 핀을 한 바이트로 인코딩합니다.
